# <a href="https://github.com/thesrinu7/Portfolio.git">Personal Portfolio website</a>

## Overview

This is my personal portfolio website built using HTML, CSS, and JavaScript. The website showcases my skills, education, projects, and contact information in a modern and responsive design.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Professional user interface
* About Me section
* Education section
* Skills section
* Projects showcase
* Resume download option
* Contact information and social media links

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Projects Included

### <a href="https://basic-calculator-127.netlify.app/">Basic Calculator</a>

* Built a basic calculator using JavaScript.
* Supports addition, subtraction, multiplication, and division.
* User-friendly interface with responsive design.

## Getting Started

1. Clone the repository:
   git clone https://github.com/thesrinu7/Portfolio.git

2. Open the project folder.

3. Run `index.html` in your browser.
